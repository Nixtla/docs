### `Calendar`

Bases: <code>[_Spec](#synforecast.overlays._Spec)</code>

Periodic profiles aligned to the series' timestamps.

**Parameters:**

Name | Type | Description | Default
---- | ---- | ----------- | -------
`cycles` |  | One or more cycles, combined as their weighted mean. | *required*
`mode` |  | 'additive' adds ``amplitude`` times the profile; 'multiplicative' scales a non-negative series by ``1 + swing * profile``. | *required*
`amplitude` |  | Additive peak, in standard deviations of the base series with ``scale='relative'`` (the default), else in series units. | *required*
`swing` |  | Multiplicative peak, as a fraction of the level, below 1. | *required*
`scale` |  | Units of ``amplitude``. | *required*
`fallback` |  | What a multiplicative calendar does on a series with negative values: 'additive' adds the additive profile instead, 'none' leaves the series unchanged. | *required*
`on_unsupported` |  | What to do at construction when a cycle cannot show at the generator's frequency (a daily cycle on daily data, any date cycle on an integer freq): 'warn' or 'skip' drops it, 'raise' fails. | *required*

Phases follow the timestamps the generator emits (UTC for an offset-aware
start). A cycle needs at least two steps per period.

### `CalendarCycle`

Bases: <code>[_Spec](#synforecast.overlays._Spec)</code>

One periodic profile aligned to the timestamps (or to the step index).

**Parameters:**

Name | Type | Description | Default
---- | ---- | ----------- | -------
`phase` |  | What the cycle repeats over: 'day' (time of day), 'week' (day and time of week), 'year' (month and time of year, so monthly data lines up with calendar months) or 'step' (every ``period`` steps, independent of freq; works with integer frequencies). | *required*
`profile` |  | 'fourier' for a smooth shape of ``harmonics`` harmonics, or 'levels' for a constant level per bin (hour of day, weekday, month, or step within the period). | *required*
`harmonics` |  | Harmonics of a Fourier profile. | *required*
`bins` |  | Bins of a levels profile; defaults to 24 (day), 7 (week), 12 (year) or ``period`` (step). | *required*
`period` |  | Cycle length in steps, for ``phase='step'`` only. | *required*
`values` |  | A fixed profile instead of a random one: ``2 * harmonics`` Fourier coefficients (cosines, then sines) or one value per bin. Random profiles draw coefficients N(0, 1/k) or levels N(0, 1). | *required*
`jitter` |  | Standard deviation of per-series normal noise added to fixed ``values``, so series share a shape without being identical. | *required*
`weight` |  | Weight of this cycle in the calendar's weighted mean. | *required*

Each cycle is normalized to peak magnitude 1 before weighting.

### `Waveform`

Bases: <code>[_Spec](#synforecast.overlays._Spec)</code>

A sharp-edged repeating template whose period is in steps.

**Parameters:**

Name | Type | Description | Default
---- | ---- | ----------- | -------
`shape` |  | 'pulse' (a rectangle of duty ``duty``), 'spike' (a pulse ``width`` steps wide), 'sawtooth' (ramp and reset each cycle), 'trapezoid' (a pulse with linear ramps), 'levels' (a jump to a random other level each cycle) or 'staircase' (a one-level step in a persistent direction each cycle). | *required*
`period` |  | Cycle length in steps; mean dwell for 'levels' and 'staircase'. | *required*
`duty` |  | On-fraction of a cycle for 'pulse' and 'trapezoid'. | *required*
`width` |  | Spike width in steps. | *required*
`ramp` |  | Trapezoid ramp per side, as a fraction of the on-time. | *required*
`levels` |  | Number of levels for 'levels' and 'staircase'. | *required*
`timing` |  | 'periodic' repeats every ``period`` steps from a random phase; 'jitter' moves each cycle start by a normal offset of standard deviation ``jitter * period``; 'renewal' draws on and off durations (whole cycles for sawtooth and level shapes) from ``renewal`` with the nominal means. | *required*
`jitter` |  | Cycle-start jitter, as a fraction of the period. | *required*
`renewal` |  | 'gamma' or 'lognormal' renewal durations. | *required*
`cv` |  | Coefficient of variation of renewal durations. | *required*
`direction` |  | 'peak' rises, 'dip' falls. | *required*
`mode` |  | 'additive' adds ``amplitude`` times the template; 'multiplicative' scales a non-negative series by ``1 +/- swing * template``. | *required*
`amplitude` |  | Additive peak, in standard deviations of the base series with ``scale='relative'`` (the default). | *required*
`swing` |  | Multiplicative peak, as a fraction of the level; at most 1 for dips. | *required*
`scale` |  | Units of ``amplitude``. | *required*
`fallback` |  | Multiplicative behaviour on a series with negative values, as for :class:`Calendar`. | *required*

### `Changepoints`

Bases: <code>[_Spec](#synforecast.overlays._Spec)</code>

Structural breaks at random or given positions.

**Parameters:**

Name | Type | Description | Default
---- | ---- | ----------- | -------
`count` |  | Number of breaks. | *required*
`kind` |  | 'level', 'trend', 'variance' or 'mixed'. | *required*
`locations` |  | Relative positions in [0, 1]; drawn from U(0.1, 0.9) where missing. | *required*
`level_changes` |  | Level jumps; drawn where missing, from U(-20, 20), or U(-3, 3) standard deviations with ``scale='relative'``. | *required*

`variance_changes` |  | Positive factors on the deviation from a rolling mean; drawn from U(0.5, 2) where missing. | *required*
`scale` |  | 'absolute' adds the changes as given; 'relative' measures them in standard deviations of the base series. | *required*

### `Observation`

Bases: <code>[_Spec](#synforecast.overlays._Spec)</code>

An observation process between the signal and the recorded readings.

**Parameters:**

Name | Type | Description | Default
---- | ---- | ----------- | -------
`floor` |  | Saturation floor, as a fraction of the way from the series' minimum (0) to its maximum (1). | *required*
`cap` |  | Saturation cap, on the same scale; above ``floor``. | *required*
`quantum` |  | Value-grid step, in standard deviations of the series entering this stage; 0 disables quantization. | *required*

`stuck_fraction` |  | Share of steps inside windows where the reading freezes. | *required*
`stuck_length` |  | Mean length of a frozen window in steps. | *required*

Missing values stay missing and never spread.
